### B01 — #559 — resolved

`internal/skills/install.go:installAgentsMDIndex` classifies the index read
error at one call site: `errors.Is(readErr, fs.ErrNotExist)` → create;
anything else → preserve, zero writes, wrapped path-naming error. Regression
tests pass: `TestInstallPreservesIndexOnReadError` (permission denied,
transient error, bare nonexistence, wrapped nonexistence) and
`TestSetupIndexReadFailureReachesPartialExit` (codex row failed, claude-code row
unaffected, native skill files still written, exit 8). `installFiles`'s
ambiguity-resolves-to-wrote posture for engram-owned skill files is deliberately
unchanged (D-08).

### W01 — #560 — warning, unchanged

`internal/setup/environment.go:84–103` is byte-identical to the first audit's
citation: `osRun` converts `*exec.ExitError` from a deadline-killed process to a
numeric exit with nil error without consulting `ctx.Err()`, so the executor's
context-error path is bypassed. The process is killed; this is a classification
defect, not an unbounded wait. Not in 04-05's scope; not worsened.
