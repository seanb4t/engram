## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| chat-completions provider → engram goroutine | Body size and arrival rate are both the provider's to choose, and both were unbounded after the useful read finished. |
| provider error body → operator log | A non-200 body is surfaced in an error the server logs, so an oversized body reaches an operator log. |
| record content → summarize request → provider | The summarize request body carries untrusted record content inside a per-request fence; a provider that reflects its request back can echo that content into the error path. |
| twin lanes → one mechanism | Two clients whose comments already call each other direct twins will drift the moment one grows a private copy of a shared control. |
