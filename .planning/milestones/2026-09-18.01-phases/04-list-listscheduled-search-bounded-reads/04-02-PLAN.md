<objective>
Move `Store.List` — the milestone's highest-exposure read — off its single unbounded full-payload
Scroll and onto Phase 3's ordered-page primitive, in both paging modes, and settle decision B's
numeric `limit` contract at the store where every lane inherits it. Phase 2's overflow regressions
that depended on the old unbounded shape are retargeted in the same plan, so `ErrResponseTooLarge`
stays reachable and RED-provable on every lane.

Decisions covered: D-01 (a zero limit resolves to the numeric page maximum, not an unbounded fetch),
D-02 (one store-level constant serving list and search), D-05 (offset mode assembles the full count
by iterating primitive pages), D-06 (a budget-cut cursor page is never the last page), D-12 (Phase 2
regression retargets). The deep-offset prefix walk (D-07) and the caller-view projection (Phase 3
D-04) are deliberately NOT here — plans 04-03 and 04-05 own them; this plan keeps the full-payload
view so its only visible change is the bound itself.

Purpose: REQ-list-bounded, REQ-list-contract-unchanged, REQ-list-limit-contract-decided.

Output: a bounded `Store.List` in both modes, one exported recall maximum, the recall gate
reclassified, and three retargeted overflow regressions.
</objective>
