two new `Memory` fields, wire them through the payload round-trip, add the
vector-preserving `IncrementAccess` primitive for the async get-path, make the

primitive existing. This is the Wave 1 root of the phase.

update-path bump, and the D-08 invariance test.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → MCP/Connect handler → store | Untrusted caller input reaches the store; access_count/last_accessed_at are server-set below this boundary, never client-supplied. |
| store → Qdrant | Payload write of the counter; RMW is last-writer-wins. |
