- **The trail and origin live in the URL** (`?from=`, `?trail=`), not in SvelteKit `page.state`: `page.state` is not applied after a reload (SvelteKit shallow-routing caveat, Context7 `/websites/svelte_dev_kit`), and the discuss-phase log rejected "refresh loses the walk". Plan 05-08 consumes both.
- **`r` is wired on /search, /rules and /scheduled** — every route that renders ResultsList with a DetailPane. The root feed (`/`) opens rows into /search and gets no `r`.
- **The keyboard-table documentation** for `r` lands with the other Phase 5 keys in plan 05-09's skill update, so the conventions skill is edited once.
