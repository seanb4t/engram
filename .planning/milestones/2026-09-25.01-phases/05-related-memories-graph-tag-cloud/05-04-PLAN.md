## Flagged assumptions (not silently dropped)

- **Compact anchors clear citations**, so the citation lane cannot say "anchor carries no citations". Its empty reason is `none — no recall-visible record shares a citation (kind + ref)`, and the no-neighbours card's tag line lists the anchor's tags without df.
- **The tag lane caption omits `n={N}`** (the UI-SPEC example): RelatedMemories does not return `n`, and the honest-feedback rule forbids inventing it. Caption: `shared tags, each weighted by rarity ln(n/df) · ranked by Σ · cap 8`. The other captions are planner defaults (the UI-SPEC gave only the tag example).
- **Hidden-state chain cards** use a dashed border and `var(--muted-foreground)` text instead of the sketch's 55% opacity, per the conventions skill's AA-safe dim rule (04-A11Y-AUDIT).
- **Way forward on the no-neighbours card** is the UI-SPEC default: `Open {short_id} in search ↗` to `/search?sel={id}`.
- **Token mapping** as in plan 05-01's Executor notes (`--text-2xs` → `calc(11 * var(--u))`, `--color-surface` → `var(--card)`, `--color-text-muted` → `var(--muted-foreground)`, `--radius-sm` → `calc(4 * var(--u))`, etc.).
