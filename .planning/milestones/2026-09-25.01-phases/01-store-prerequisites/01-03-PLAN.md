- `type RelatedEdgeType string` with exported consts `RelatedEdgeSupersession` "supersession", `RelatedEdgeCitation` "citation", `RelatedEdgeTag` "tag", `RelatedEdgeVector` "vector" (doc: this is the canonical order, used for admission and for each entry's Edges).

- `type RelatedEdge struct` with json-tagged fields: `Type RelatedEdgeType` (`type`); `Score float32` (`score,omitempty` — vector: raw Qdrant cosine similarity); `SharedTags []WeightedTag` (`shared_tags,omitempty`) and `TagWeight float64` (`tag_weight,omitempty`) — tag: shared tags with their rarity weight and the sum, filled by plan 01-04; `SharedCitations []CitationRef` (`shared_citations,omitempty`) — citation: shared kind+ref pairs, filled by plan 01-04; `Direction SupersessionDirection` (`direction,omitempty`) and `Depth int` (`depth,omitempty`) — supersession: hops from the anchor, 1 = direct link. Doc: evidence is per type and never comparable across types (D-12).
- `type RelatedMemory struct` with `Memory Memory` (json `memory`) and `Edges []RelatedEdge` (json `edges`) — doc: D-06's documented rule, one entry per candidate, Edges lists every edge type that reached it in canonical order.
- `type RelatedResult struct` with `Anchor Memory` (json `anchor`), `Related []RelatedMemory` (json `related`), `Truncated bool` (json `truncated,omitempty`) — doc: Truncated means the total ceiling left out at least one vector neighbour.
- Unexported `type relatedCandidate struct { id string; edge RelatedEdge }` and `func relatedEdgeRank(t RelatedEdgeType) int` returning supersession 0, citation 1, tag 2, vector 3.
- Consts with provenance doc comments (house style of `defaultNearDuplicateTopK`): `relatedVectorDefaultK = 8` (vector neighbours when k is 0; D-12's roughly 8) and `relatedTotalCeiling = 64` (hard cap on entries; documented invariant: the supersession, citation and tag caps together stay below it, so only the vector edge — the one a caller widens with k — can reach it, and no type crowds out another).

Functions:
- `func edgeFilter(f *qdrant.Filter, anchorID string, extra ...*qdrant.Condition) *qdrant.Filter`: returns a NEW filter whose Must is `qdrant.NewFilterAsCondition(f)` followed by extra, and whose MustNot is `qdrant.NewHasID(qdrant.NewID(anchorID))`; never mutates f (mirrors includeIDs).

Doc: fetch under the SAME f the sub-queries used — the enforcement point; admission order is by type, never by a blended score.
