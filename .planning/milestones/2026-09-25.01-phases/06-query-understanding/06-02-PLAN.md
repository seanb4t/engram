## Flagged assumptions (not silently dropped)

- **Tokenization (D-09 discretion):** tokens are maximal runs of Unicode letters, digits, `-` and `_`, lowercased; a hyphen part must be 3+ runes so `go-to` does not match every query containing "go"; the full-token rule still lets a tag `go` match the word "go". The cap of 8 mirrors the tag picker's top 8.
- **Scope option names are the scope strings themselves** plus the reserved option `none`; a scope literally named `none` (not a valid engram scope shape) is dropped from the options.
- **Store failures degrade silently to the client** (no error UI exists by design, D-12); the Warn lines carry no query text so NLQ-04 holds on the failure paths too.
