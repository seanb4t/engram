## Flagged assumptions (not silently dropped)

- **Audit fields beyond D-16's minimum:** outcome, questions_asked and fallback_class ride along (bounded, text-free) so an offline grader can tell "no suggestion" from "fallback"; the owner is deliberately NOT logged (D-16 names query text plus labels only).
- **The audited query is the trimmed text as received** — not the 2000-rune truncation the decision call sees — so the grader sees what the operator typed.
- **The empty-query path stamps outcome skipped with zero counts** (it is still an enabled call); the off path stamps nothing, so attribute absence reads as "off", matching the rerank telemetry convention.
