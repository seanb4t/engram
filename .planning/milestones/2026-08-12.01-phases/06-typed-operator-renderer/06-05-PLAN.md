Convert the three two-level spine-review reports whose text output is a list, not a sentence.

its keep — today each hand-builds its row lines with `fmt.Fprintf` inside a loop, and each of those
loops is a place text and json could drift. Under D-01 the rows come from the document, so the loops
are deleted rather than rewritten.

under the shared identity gate.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Qdrant payload -> operator CLI process | Record ids, scopes, categories and tags in purge and archive rows originate from callers. |
| operator's own flag values -> `purgeRerunCommand` -> rendered output | A `--scope`, `--category` or `--tags` value is echoed back into the re-run command string. |
| operator CLI process -> terminal / pipe / log | Rendered bytes reach a device that interprets control sequences. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Information Disclosure | `archiveReportDoc`, `archiveResultDoc`, `purgeReportDoc` | high | mitigate | All three remain hand-declared structs carrying ids, outcomes, counts, scopes, categories and tags only — never record content or summary text, which is what `archiveReportDoc`'s own comment says the type enforces. Task 1 changes no field; Task 2's only field addition is a command string built from the operator's own flags. Verified by the `git diff` criteria. |
| T-06-09 | Information Disclosure | `purgeReportDoc.Rerun` | medium | mitigate | The re-run string is assembled by `purgeRerunCommand` from the operator's OWN flag values (`--class`, `--scope`, `--category`, `--tags`, `--older-than`) and contains no record id and no record content. It was already printed verbatim in text mode before this phase; adding it as a key discloses nothing new and makes it available to the json lane that previously lacked it. |
| T-06-03 | Tampering | rendered id and tag values in this group | medium | mitigate | Inherited from plan 06-01: `sanitizeViewValue` strips C0 controls and DEL from every rendered value, so a tag or scope carrying a newline cannot forge an extra purge row that appears to name an id the sweep never touched. This group is the highest-value case for that mitigation because its rows ARE id lines. |
| T-06-SC | Tampering | package-manager installs | low | accept | No installs — Go source edits and one new test file. |
