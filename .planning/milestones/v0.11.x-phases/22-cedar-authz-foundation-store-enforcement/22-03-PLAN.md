gate it does today.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| id-addressed request -> record fetch -> PDP decision | An unauthorized caller must be indistinguishable from a missing-id caller (no existence leak). |
| PDP Diagnostic -> caller / logs / spans | Policy ids and reasons are operator-audit data; they must never reach a caller and must not carry PII into logs/spans. |
| absent record -> gate | Cedar must not be consulted (or fabricate a decision) for a record that does not exist. |
