Verified at planning time (line numbers approximate; Phase 4 does not touch these files):

- `cmd/engram/operator_view.go`: `type viewField struct { Key, Label, Value string; Rows []string }` (~line 28). Its doc says Rows is "one rendered line per array element, or a single rendered line for an object-valued key; nil for a scalar key". `func viewFields(doc any) ([]viewField, error)` (~line 45) has three cases. `case '[':` builds `rows := make([]string, 0, len(elems))`, and per element: object → `viewRow(elem)`, array → `strings.Join(flattenNested("", elem), " ")`, scalar → `viewScalar`. `case '{':` (~line 102, two tabs of indent, the first two-tab `case '{':` in the file) does `row, err := viewRow(raw)` then `field.Rows = []string{row}`. `default:` does `field.Value = viewScalar(raw)`.
- `viewRow` (~line 215) returns `strings.Join(parts, " ")`. For `{}`, or an object whose only values are empty objects, `parts` is empty and the row is `""`. A registered row-field renderer (`rowFieldRenderers`, e.g. `verdict`) or `flattenNested` handles nested values. Every string passes through `sanitizeViewValue`.
- `renderOperatorView` (~line 422) prints `"  "+Label+padding+Value`, trailing spaces trimmed when `Value == ""`, then `"    "+row` for each row. Its doc: "the output ends with exactly one trailing newline and never a trailing blank line". An empty row therefore prints a four-space line today.
- `cmd/engram/operator_view_test.go`: `assertViewIdentity(t, name, doc)` (~line 120), `jsonTopLevelKeys`, `countTopLevelFieldLines`. `TestOperatorViewEmptyShapes` (~line 262) pins "a container key with no elements carries zero rows" for arrays. Its `null_ptr` case expects `Rows` nil for a scalar.
- `cmd/engram/operator_output_test.go` `TestOperatorViewFixturesHaveNoUnsanitizedNesting` derives `wantNewlines` from `len(f.Rows)`. No fixture has an object-valued top-level field, so the Task 2 change cannot move its count.
- Operator report docs checked: `migrateOutputDoc`, `migrateStatusReportDoc`, `revertOutputDoc`, `pruneOutputDoc`, `summarizeOutputDoc`, `reindexOutputDoc`, `migrateSetOwnerReportDoc`, `migrateRemapReportDoc`, `spineScanReportDoc`, `verifyReportDoc`, `consolidateReportDoc`, `purgeReportDoc`, `archiveReportDoc`, `setupReportDoc`, `versionDoc`.
