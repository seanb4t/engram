- `decisions.go`, `(*Decisions).Create(ctx, components.DecisionsRequest, ...operations.Option) (*components.DecisionsResponse, error)`:
  - The base URL is `operations.CreateAPIAlphaDecisionsServerList[0]` (`https://openrouter.ai`, in `models/operations/createapialphadecisions.go`). Only the per-call `operations.WithServerURL` replaces it, and the client-level `openrouter.WithServerURL` does not reach this operation.
  - The operation URL is `url.JoinPath(baseURL, "/api/alpha/decisions")`. The SDK appends `/api/alpha/decisions`, not D-03's `/alpha/decisions`, so a LiteLLM pass-through base of `https://<gateway>/openrouter` would produce `/openrouter/api/alpha/decisions`. Spike 002 observed that path return 404 on the gateway.
  - With no retry config, it retries on `5XX` and connection errors with backoff (500 ms initial, 60 s max interval, exponent 1.5, max elapsed 3,600,000 ms).
  - It reads every response body through `internal/utils.ConsumeRawBody`, which calls `io.ReadAll` with no bound.
  - A non-2xx JSON body is decoded into a per-status `sdkerrors.*ResponseError`. If that decode fails, the raw unmarshal error is returned with no status attached. RESEARCH found the error-data `code` field typed `int64`, and LiteLLM sends `code` as a string.
- `models/components`:
  - Request fields: `Model string`, `State` (a union of string, `map[string]any` and `[]any`), `Questions map[string]Questions` (a noul, choice or score union), `Provider` (optional `ProviderPreferences`), `SessionID *string` and `Trace *TraceConfig`.
  - Question fields: noul `True`/`False`, choice `Criteria map[string]*Criteria`, score `Criteria []Criterion`, and `Instructions` on each. Each is a union of string, `map[string]any` and `[]any`.
  - Answers: noul `Noul float64`. Choice `Choice string`, `Confidence *float64`, `Probabilities map[string]float64`. Score `Score float64`, `Confidence *float64`, `Probabilities map[string]float64`, and `Legend map[string]Legend`, whose union members are `Str *string`, `MapOfAny map[string]any` and `ArrayOfAny []any`. The `Answers` union carries `UnknownRaw json.RawMessage` for unknown discriminators.
  - Response: `Answers`, `ID *string`, `Model string`, `Provider *string` and `Usage{Cost *float64, InputTokens int64, OutputTokens int64}`.
- `systemone.go`: `SystemOne.Create` sends the same request/response types to a sibling path (`url.JoinPath(baseURL, "/systemone")`).
