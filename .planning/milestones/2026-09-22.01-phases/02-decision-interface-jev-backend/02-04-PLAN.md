<objective>
Grow the tracer's noul-only contract into the full provider-neutral System One interface. Every backend and every future caller builds on it.

- **DEC-02:** choice and score questions and answers, carried verbatim.
- **D-09:** cheap structural validation that returns named errors with no network call, plus `Request.Add`, which makes D-09's duplicate-name rule enforceable on D-10's map shape.
- **D-12:** the named, `errors.Is`-able failure classes and the caller contract, defined once in `internal/decide` so every backend classifies into the same vocabulary. Plan 02-07 does the jev classification.
- **D-10:** `DecideMany`, the bounded worker pool with per-item results in input order, exposed on the `Decider` interface so callers never need the concurrency setting.

Purpose: Phase 3 (consolidate verdicts, choice questions over many pairs) and Phase 4 (rerank, many noul questions) consume exactly this contract. A second backend (DEC-F2) implements it without caller changes.
Output: `errors.go`, `validate.go`, `many.go` and tests. `decide.go` grows the choice/score types and the `DecideMany` interface method. `jev.go` gets validation and delegation.
</objective>
