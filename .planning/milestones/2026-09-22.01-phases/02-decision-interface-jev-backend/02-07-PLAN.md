<objective>
Harden the Jev backend's failure path and complete its telemetry, so a decision call can never surprise its caller.

- **DEC-04 / D-12:** classify by HTTP status alone into the named classes, identically for OpenRouter's numeric and LiteLLM's string error dialects. Detect `max_tokens_exceeded` structurally. Bound the success body (named too-large error), the error body (4096 bytes) and the drain (bytes and time).
- **D-11:** exactly one jittered retry, only on 429/5xx or a non-timeout transport failure, inside the one timeout budget.
- **DEC-06 / D-13:** the `decide` span's status word comes from `decide.Status`. Failure spans stay fully attributed. Usage attributes are omitted when absent. Cost is exact. No metrics instruments are added (a deferred idea).
- **Prohibition P2:** no record content or credential in anything engram authors.

Purpose: Phases 3 and 4 treat any error as "no decision" and continue. This plan makes that safe to do cheaply, with typed, bounded, fast failures.
Output: `classify.go`, fixtures, the retry and bounds logic in `jev.go`, and three test files.
</objective>

(2) New `internal/decide/jev/classify.go` (package `jev`, SPDX):
- An unexported `type errorEnvelope struct { Error struct { Message string; Code json.RawMessage } }` with json tags `error`, `message` and `code`. Decoding `code` as `json.RawMessage` accepts OpenRouter's number and LiteLLM's string alike, and the code is never used for classification.
- `func classifyStatus(status int, body []byte) error` returns a `*decide.Error` with `Status` set and `Detail` bounded to `maxErrorBodyBytes`. Detail is `error.message` when the body decodes as the envelope, else the trimmed raw body. The Kind:
  - 401, 402, 403: Auth.
  - 400: `ErrDecisionContextTooLarge` if `contextTooLarge(body, message)` holds, else BadRequest.
  - 413: ContextTooLarge.
  - 429: RateLimited.
  - 500 and above: Unavailable.
  - any other 4xx: BadRequest.
  - anything else: Unavailable.
- An unexported `func contextTooLarge(body []byte, message string) bool`. It returns true only when JSON-decoding into `struct{ Detail struct{ ErrorType string } }` (tags `detail`, `error_type`) yields `max_tokens_exceeded`, first for the whole body, then for `message[i:]`, where `i` is the index of the first `{` in the message. The doc comment names this the single structured exception D-12 allows ("detected structurally where possible"), and says a message is never substring-matched for control flow.
- `func classifyTransport(ctx context.Context, err error) error`:
  - `errors.Is(err, context.Canceled)` with `ctx.Err()` also `context.Canceled` (the caller cancelled): return `err` unchanged.
  - `errors.Is(err, context.DeadlineExceeded)`, or `errors.As` into a `net.Error` whose `Timeout()` is true: `&decide.Error{Kind: decide.ErrDecisionTimeout, Err: err}`.
  - otherwise: `&decide.Error{Kind: decide.ErrDecisionUnavailable, Err: err}`.
- `func isRetryable(err error) bool` returns `errors.Is(err, decide.ErrDecisionRateLimited) || errors.Is(err, decide.ErrDecisionUnavailable)`.
