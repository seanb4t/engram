<objective>
Make `task eval:retrieval`'s two correctness gates trustworthy. This closes #353 (EVAL-01) and #354 (EVAL-02).

- **D-14:** The differ test's symmetric-config skip reads the resolved `*config.Config` that the embedder under test was built from. `server.StoreAndEmbedderFromEnvNoEnsure` is widened to return that config. There is no second config load.
- **D-15 (revised, user-confirmed):** `ENGRAM_RETRIEVAL_EVAL` is resolved by a package-local koanf load that uses the same `ENGRAM_` prefix and precedence as production. It is **not** registered in `internal/config`, and it never calls `Validate()`. `TestMain` still short-circuits before any Docker startup when the gate is off.
- **D-13:** The differ gate compares by cosine distance with a 1e-3 epsilon, replacing bit-identity. A NaN/Inf, zero-norm, or length-mismatched vector is a hard fatal, and the PASS log no longer claims a cause.

Purpose: Phase 1's reranker decision (plans 01-04 to 01-06) and Phase 4's Jev gate both rest on this eval, so its gates must be correct first.
Output: `gate.go` and `vector.go` with hermetic tests, the widened loader and all its callers, and the rewritten gates in `retrieval_eval_test.go`.
</objective>
