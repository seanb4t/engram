<objective>
Mirror the proven MCP lane onto the wire, so cross-spine recall is available at MCP↔Connect parity
through additive proto fields (ROADMAP criterion 4).

This plan carries the phase's one permanent commitment — six protobuf field numbers, confirmed by
the wave-2 checkpoint — and its one deliberate divergence from the sibling implementation the rest
of the phase copies. `SearchDiscoveries` maps an empty scope to cross-spine at `connectapi.go:266`.
Memories must NOT. That mapping exists only to preserve a contract predating the typed core;
memories have no such contract, and inferring it would silently widen every existing empty-scope
Connect call from "returns nothing" to "returns everything readable" — a behavior change no caller
opted into. Connect also has no empty-scope guard today at all, so one is added here rather than
inherited.

Purpose: put the capability on the second transport without copying the one thing about the sibling
that must not be copied.
Output: proto fields, regenerated Go and TS clients, both Connect handlers, and the negative test
that keeps the non-inference true.
</objective>
