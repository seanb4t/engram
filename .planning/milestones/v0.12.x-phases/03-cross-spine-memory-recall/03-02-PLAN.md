<objective>
The tracer. Wire ONE path — MCP `search_memory` with `cross_spine=true` — through every layer this
phase touches, end to end, and prove it against real Qdrant before expanding anywhere else.

That path is: the tool argument, the D-03 guard, the transport-neutral core request, the typed core,
`Store.Search`, and the `ownerScopeFilter` composition Qdrant actually evaluates. No `list_memory`.
No Connect. No `searched_scopes`. One entry point, one call site, production quality throughout.

This is the plan where the phase's architectural risk lives: it is the commit that changes what
`scope == ""` MEANS at the store layer, from "match the literal empty-string scope payload" to
"match everything this caller may read". Plan 03-01 landed the pin on the authorization clause
first, in its own commit, so that this edit is made against a tree where the property is already
guarded (D-18).

Purpose: prove the architecture end-to-end on one slice, so an architectural dead-end costs one
commit instead of five layers.
Output: cross-spine search works on the MCP lane, with the guard, the log discipline, and the
handler-level two-owner isolation proof.
</objective>
