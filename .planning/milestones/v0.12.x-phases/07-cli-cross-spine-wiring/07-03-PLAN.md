live tree that `collectFlags` (`cmd/engram/catalog.go:109-128`) walks the live `cobra` flag set via
`pflag.FlagSet.VisitAll` and emits each flag's `Usage` verbatim at `:121`, with no hardcoded flag list
anywhere in `catalog.go`; `buildCatalog` (`:52-76`) iterates `root.Commands()` and special-cases only
`help`, `completion`, and hidden commands. The pre-existing `TestCatalogEnumeratesEveryFlag`
(`catalog_test.go:172-213`) already asserts set equality between the catalog's flags and the live
tree's for `search`, `list`, and `store`, and already fails on an empty `Usage`. The catalog therefore
absorbs `--cross-spine` with zero catalog code.

Task 1 is a **verification plus a guidance assertion**, not an implementation. D-07's open question
("that must be verified, not assumed") is answered by running the gate and adding one test that pins
the guidance content the catalog carries, which no existing test checks.
</no_catalog_implementation>
