flag to shared guard to request field to server to coverage footer, with the guard pinned against
the server's own rule at compile time.

without ever wiring it. This plan proves the whole path on one command before plan 07-02 expands it
to `engram list`.

`--cross-spine` flag and D-00 help text on `searchCmd`, the sole authorized `internal/` change
(`EffectiveSearchScope`), and the guard's parity, behavior, and baseline test set.
