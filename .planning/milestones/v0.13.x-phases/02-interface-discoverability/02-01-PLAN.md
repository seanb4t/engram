Prove the whole Phase-2 architecture end-to-end on ONE rule: the
`scope-required-unless-cross-spine` rule from REQ-conditional-rules-stated's own worked example.

Purpose: this phase's central claim is that a conditional rule can be declared exactly once and
reach every surface that advertises it. Two findings make that non-obvious and must be proven before
anything is widened: (1) `cmd/engram/client_search.go` is a `client_*.go` file that
`TestClientFilesImportBoundary` denylists from importing `internal/server`, so the rule value cannot
live in `internal/server` if cobra `Usage` is to compose it — it must live in a new leaf package;
(2) the generate-commit-drift-check contract must work over four prose trees including the published
docs site and the released skill.

Output: `internal/surfaces` leaf package with one declared rule (D-03), `conditionalErrf` (D-04), one
converted rejection site, the composed cobra `Usage`, a working `internal/surfacesgen` generator
writing anchored regions whose contents are generated from the registry (D-06), anchored regions in
five of D-05's six prose surfaces, the single `task surfaces:gen` target and the single CI drift job
that re-runs it and fails on a dirty tree (D-07).
