## Pattern Assignments

### `internal/store/store.go` — `Store.Supersede` (store method, CRUD)

**Analog:** itself, current single-target form.

**Current full function** (`store.go:1996-2043`):
```go
func (s *Store) Supersede(ctx context.Context, newMem Memory, vec []float32, target string, subj Subject) (err error) {
	ctx, span := tracer.Start(ctx, "store.Supersede",
		trace.WithAttributes(attribute.String("engram.owner", ownerOf(subj))))
	defer span.End()
	start := time.Now()
	defer func() {
		telemetry.RecordStoreOp(ctx, "Supersede", start, err)
		if err != nil {
			span.RecordError(err)
			span.SetStatus(codes.Error, err.Error())
		}
	}()

	// 0. Per-target lock, held through the back-stamp (CR-01)
	unlock, err := s.locker.Lock(ctx, target)
	if err != nil {
		return err
	}
	defer unlock()

	// 1. Owner-only write gate on the TARGET
	targetRec, err := s.getWritable(ctx, target, subj, authz.ActionWrite)
	if err != nil {
		return err // ErrNotFound: not owner, or doesn't exist — fail-closed, no leak.
	}
	// 2. Single-hop / cycle rejection (D-05/D-06)
	if targetRec.SupersededBy != nil && *targetRec.SupersededBy != "" {
		return fmt.Errorf("%w: %s", ErrAlreadySuperseded, target)
	}
	// 3. Store the new record
	if err := s.Upsert(ctx, newMem, vec); err != nil {
		return err
	}
	// 4. Back-stamp the target
	_, err = s.client.SetPayload(ctx, &qdrant.SetPayloadPoints{
		CollectionName: s.collection, Wait: qdrant.PtrOf(true),
		Payload:        qdrant.NewValueMap(map[string]any{"superseded_by": newMem.ID}),
		PointsSelector: qdrant.NewPointsSelectorIDs([]*qdrant.PointId{qdrant.NewID(target)}),
	})
	return err
}
```

**What to copy verbatim:** the tracer/span/telemetry wrapper (unchanged shape, `target` becomes
`targets []string` in the attribute or a joined summary — do not drop `RecordStoreOp`/span error
recording); `getWritable(ctx, id, subj, authz.ActionWrite)` call shape (loop it per target, per D-05
"checked for every target before the survivor is written" — this pins the **order change**: D-05
requires the checks in step 1/2 to run for **every** target before step 3's `Upsert`, i.e. don't
interleave check-then-upsert-then-check like the loop naively suggests); the `SetPayload` call shape
with `PointsSelectorIDs` already accepting a slice at line 2040 — literally pass the resolved,
deduped, sorted `targets` slice instead of a 1-element slice.

**What must change (new, not in the analog):** lock acquisition becomes the sorted-multi-lock loop
(see Pattern Assignments → `locker.go` below); after the `SetPayload` call, an error branch must run
the D-07/D-08/D-15 compensation: delete the survivor (`s.Delete` or equivalent primitive — grep for the
existing `Delete` implementation used by `delete_memory`), then re-read the **full requested target
set** via `s.Get` per id (or a batched read) and clear `superseded_by` on any target whose value equals
the deleted survivor's id. Log the survivor id and any still-dangling target ids via this package's
existing structured-logging convention (see Compensating cleanup pattern below) — do not surface them
to the caller; the returned error stays the original stamp error.

**Do NOT copy:** the assumption that a `SetPayload` error means nothing was written (Pitfall 1 in
RESEARCH.md — this premise is false for N>1 and the design must not import it).

**Analog for the encoder side** — `store.go:498-500` (must widen from a single `p["supersedes"] =

**Precedent for a genuinely tolerant string-or-list decode:** `tagsFromPayload` (grep `internal/store/store.go`
for its definition — it already reads `p["tags"]` as a list). Read `tagsFromPayload`'s exact
`GetListValue()`/`GetKind()` branch before writing the new decoder — it is the one existing function in
this codebase that decodes a list-shaped payload value, and the new `supersedes` decoder should follow
its `Kind`-branching shape rather than inventing one. **Confirmed failure mode to guard against**
(RESEARCH.md Pitfall 4, `qdrant/json_with_int.pb.go:214-240`, vendored):
```go
func (x *Value) GetStringValue() string {
	if x, ok := x.GetKind().(*Value_StringValue); ok {
		return x.StringValue
	}
	return ""
}
func (x *Value) GetListValue() *ListValue {
	if x, ok := x.GetKind().(*Value_ListValue); ok {
		return x.ListValue
	}
	return nil

```
`GetStringValue()` on a `ListValue`-kind `Value` returns `""` with no error — the new decoder MUST
branch on `Kind`/check `GetListValue()` first, never call `GetStringValue()` unconditionally on
`p["supersedes"]`.

**Downstream renderers to check (no separate DTO layer — `Memory` struct is returned directly):**
`get_memory` (`tools.go:1607`, per RESEARCH.md) and `list_memory --full` — both just serialize the
`Memory` struct's `json:"supersedes,omitempty"` tag; changing `Supersedes` from `*string` to `[]string`
(or keeping `*string` semantics but writing a list) propagates automatically through `encoding/json` —
confirm no other code path type-asserts `Memory.Supersedes` as `*string` (grep before editing).

### `internal/store/locker.go` — sorted multi-lock acquisition (D-10)

**Analog:** the unchanged `TargetLocker` interface and `inProcessTargetLocker.Lock`, verbatim
(`locker.go:25-58`):
```go
type TargetLocker interface {
	Lock(ctx context.Context, key string) (unlock func(), err error)
}

type inProcessTargetLocker struct {
	mus sync.Map // key: string target id -> *sync.Mutex
}

func newInProcessTargetLocker() *inProcessTargetLocker {
	return &inProcessTargetLocker{}
}

func (l *inProcessTargetLocker) Lock(ctx context.Context, key string) (func(), error) {
	if err := ctx.Err(); err != nil {
		return nil, err
	}
	muAny, _ := l.mus.LoadOrStore(key, &sync.Mutex{})
	mu, _ := muAny.(*sync.Mutex)
	mu.Lock()
	return mu.Unlock, nil
}
```
**No interface change.** The multi-lock loop is new call-site code inside `Store.Supersede`, not a
`locker.go` change. Copy the loop shape from RESEARCH.md's Pattern 2 (illustrative, not existing code):
sort+dedupe the **resolved** target UUID set before the loop (dedup happens upstream of/at the very top
of this loop — never inside it, and never on raw caller input strings, per Pitfall 2), acquire in
sorted order accumulating `unlocks []func()`, release in reverse via a single `defer` closure. On a
mid-loop lock acquisition error, unwind whatever was already acquired before returning (don't just rely
on the deferred full-reverse-release, which won't run partial-acquisition cleanup correctly if written
naively — write the partial-unwind explicitly as shown in RESEARCH.md's sketch).

	name := fmt.Sprintf("%d:%s:%d:%s:%d:%s",
		len(owner), owner, len(scope), scope, len(key), key)
	return uuid.NewSHA1(engramIdempotencyNS, []byte(name)).String()

**`checkIdempotentReplay` — reuse verbatim as machinery, call it with the new merge fingerprint instead
of `contentFingerprint(a)`:**
```go
// idempotency.go / tools.go:970-989, unchanged signature and control flow
func (d *deps) checkIdempotentReplay(ctx context.Context, owner string, a storeArgs) (replay bool, id, shortID, pointID string, err error) {
	if a.IdempotencyKey == "" { return false, "", "", "", nil }
	if len(a.IdempotencyKey) > maxIdempotencyKeyBytes { return false, "", "", "", argErrf(...) }
	pointID = idempotencyPointID(owner, a.Scope, a.IdempotencyKey)
	existing, gerr := d.st.Get(ctx, pointID)
	switch {
	case errors.Is(gerr, store.ErrNotFound): return false, "", "", pointID, nil
	case gerr != nil: return false, "", "", "", gerr
	}
	if contentFingerprint(a) == existing.IdempotencyFingerprint {
		return true, existing.ID, existing.ShortID, "", nil
	}
	return false, "", "", "", fmt.Errorf("idempotency key %q reused with different content: %w", a.IdempotencyKey, store.ErrIdempotencyConflict)
}
```
Either add a `checkIdempotentReplay`-alike wrapper for the merge case (since the signature takes
`storeArgs`, not the target list) or a new sibling function that inlines the same switch but compares
against `mergeFingerprint(a.storeArgs, targets)` instead of `contentFingerprint(a)` — planning's call
