command's declared exclusive groups and assert the pair appears in one. Cobra stores groups in the
flags' annotations (`cobra.mutually_exclusive` on each member flag), so read the annotation off the
`*pflag.Flag` rather than reaching for unexported `Command` state — confirm the exact annotation key
by reading `flag_groups.go` in the vendored cobra before writing the lookup.

then extract the flag names named in the same sentence. A flag naming a peer that does not exist on
