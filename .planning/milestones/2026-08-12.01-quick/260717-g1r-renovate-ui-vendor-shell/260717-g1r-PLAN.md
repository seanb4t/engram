# Quick Task 260717-g1r: Fix #301 — Renovate ui/ vendored-SPA self-heal (spawn cd ENOENT)

## Problem

`.github/renovate.json`'s ui/ `postUpgradeTasks` command is a single shell pipeline
(`cd ui && pnpm install && pnpm build && rm -rf … && cp …`). Renovate runs postUpgradeTasks
**shell-free** — it shlex-splits the string and spawns `argv[0]` directly — so `cd` (a shell
builtin) fails with `spawn cd ENOENT` and every `ui/` dep bump fails (#383, #384, …), surfacing
as a Repository Problem on the Dependency Dashboard (#155). The external homelab blockers
(allowlist + node/pnpm) are already cleared; this is now an in-repo command-shape bug.

## Fix

Wrap the existing pipeline in a single `bash -c '…'`. `bash` is present on the runner
(`/usr/bin/bash`), shlex keeps the quoted chain as one argv (`["bash","-c","cd ui && …"]`), and
the `&&` short-circuit interlock — a failed `pnpm build` never reaches `rm -rf` — is preserved.
Add `installTools.pnpm: {}` so the runner installs pnpm at the repo's `packageManager` major
(bundled runner pnpm is an older major) for byte-reproducible output.

**Constraints honored (from #301):** (1) shell-free spawn via `bash -c`; (2) build→destroy
interlock preserved by the in-bash `&&`; (3) byte-reproducibility unchanged (`svelte.config.js`
pins `version.name`); (5) pnpm major pinned via `installTools` (schema-valid form is `{"pnpm":{}}`
— a version string is rejected; version resolves from `packageManager: pnpm@11.11.0`).

**NOT resolved here (external, user-owned):** constraint (4) — the self-hosted
`selfhosted-cluster` `allowedCommands` allowlist pins the OLD command by anchored exact-match. It
must be updated to the NEW command string and landed **cluster-first**, or the `ui/` bump PRs get
rejected in a new way in between. This branch MUST NOT merge until that lands.
