<objective>
Ship `engram spine-review verify`: excerpt-anchored citation drift classification into four tiers
(valid / moved / broken / unverifiable), bounded to the file the citation names and to the repo the
command runs in, exiting 0 by default with an opt-in `--fail-on` for CI.

Purpose: an operator reading a clean report must be able to tell "checked and fine" from "never
looked at". The moved tier exists so ordinary refactoring does not train an operator to ignore the
verifier — GitHub issue #355 is the live drift fixture this classification is chosen to get right.

Output: a pure tier classifier, a Subject-less citation enumeration, the leaf command with its
`--output` and `--fail-on` flags, a registered conditional rule anchored on its surfaces, and a
published `exitFindings` code wired through every surface that derives from the taxonomy.
</objective>
