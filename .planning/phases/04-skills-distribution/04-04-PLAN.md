<objective>
Close the phase: give the one target with no machine of its own — the `generic` pseudo-runtime — the
curation guidance in its deliverable, make `engram setup --help` tell the truth about what the
command now does, and prove the whole report end to end across all four runtime shapes in one
invocation.

`generic` exists so an unsupported MCP client is "a documented manual path rather than a dead end". A
dead end for the curation guidance is still a dead end, and a user on an unsupported client is the
one class with no other way to obtain it — which is why D-11 puts the skills in generic's deliverable
even though generic never writes anything.

Purpose: everything before this plan makes engram install skills. This plan makes engram TELL an
operator that it does, and proves the aggregated report holds across every runtime shape at once.

Output: generic's skills payload, updated help and headline prose, one deliberately regenerated
golden, and a four-runtime end-to-end report test.
</objective>
