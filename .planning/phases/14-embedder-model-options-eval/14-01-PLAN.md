<objective>
Build the permanent, skip-gated retrieval-eval differ-case that proves engram's
asymmetric query/document embedding actually takes effect — the Pitfall-12
correctness gate for REQ-embed-gemini-direct (#331).

Per the research supersession, `gemini-embedding-2` does NOT honor a `task_type`
JSON param; its asymmetry is a text prefix on the input string, which maps to
engram's existing `ENGRAM_EMBED_QUERY_INSTRUCTION`/`ENGRAM_EMBED_DOCUMENT_INSTRUCTION`
mechanism (D-03 — no new wiring). The differ-case embeds one identical string
query-side and document-side through the production embedder and asserts the two
vectors differ (D-04). It PASSES under the correct instruction-prefix recipe and
FAILS if an operator misconfigures the no-op `*_PARAMS`/`task_type` mechanism —
exactly the silent recall regression Pitfall 12 warns about, made catchable.

Purpose: A re-runnable regression guard (D-05) that turns a silent recall
degradation into a hard test failure.
Output: A new skip-gated differ probe + assertion in `internal/retrievaleval/`.
</objective>
