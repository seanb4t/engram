<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Subject (caller identity) -> read-filter builder | The converted owner/kind must fail closed for a nil/unknown Subject and must never grant a broader bucket set than today. |
| PDP bucket decision -> Qdrant filter | The decision must compile to a filter whose authz clause is the outer Must; a mis-composition could leak another owner's records. |
| store <-> handlers | The PDP must stay owned by the store; a handler consulting it would reintroduce a bypassable gate (DEC-cgb). |

| T-22-06 | Information Disclosure / Denial of Service | bulk recall path | high | mitigate | DecideBucket called O(buckets-per-request), never per record (`TestSearchAuthzCallCount`); no fetch-then-authorize — Qdrant executes one filtered query. |
| T-22-07 | Elevation of Privilege | principalParams converter (empty-owner / anonymous bucket) | high | mitigate | ok-bool fail-closed for nil; anonymous(owner="") receives only the owner=="" bucket (shared_read requires owner!=""), never shared; Subject sealed sum not widened (DEC-12c). |
