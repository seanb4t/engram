Close the hard prerequisites that block every write feature in Phase 19:

Both the token and the Button variant are prerequisites for the D-06 delete confirm dialog and D-02 destructive row actions (Plan 03).

Purpose: unblock all downstream write UX and eliminate the vendored-gen-drift class of bug (relates to Phase 21 "Renovate vendored-SPA drift").
Output: reproducible structure-preserving re-vendor task + CI guard + compile gate, re-vendored gen client with its `buf/validate` dep, `--destructive` tokens, and a `destructive` Button variant — each with a source/compile-asserting test.
