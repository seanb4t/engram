<objective>
Build the slide-over create/edit forms (D-01) that drive the memory/discovery mutations:

- `MemoryFormSheet.svelte`: a right-side shadcn `Sheet` for both create and edit. Field set (per UI-SPEC): content (textarea, required), scope (defaults to the current route scope; editable in CREATE, DISABLED in edit), category (select, required in CREATE, DISABLED in edit), tags (minimal chip input built from input + badge), visibility (default private; toggling to shared surfaces the embedded `ShareWarningInline` acknowledgement — D-07 — and sets a `shared` intent the Plan-04 create composite commits via SetVisibility), summary (optional), and an optional schedule window (not_before/not_after) behind a "schedule this memory" checkbox shown in CREATE mode ONLY (memory-only — D-03; ScheduleMemoryRequest has no id so an edit can never schedule). On submit it calls the appropriate Plan-04 hook (create — with `shared` intent; schedule — with `shared` intent when a window is set in create mode; or update in edit mode with a dirty-mask of only-changed fields). On a post-retry hard auth failure it keeps the sheet open, renders the inline re-auth prompt with a Re-authenticate button, and preserves all entered values; because clicking Re-authenticate triggers a full `/auth/login` OIDC redirect whose callback returns to `/ui/` (NOT the originating route, and `/ui/` has no write host), the form persists a resume envelope (`returnPath`/`kind`/`mode`/`recordId`/`values`) to `sessionStorage` before navigating — Plan 06 consumes it on `/ui/` startup to route back and reopen the correct sheet, and this form restores `values` on reopen so the values genuinely survive re-auth (D-09).
- `DiscoveryFormSheet.svelte`: a create-only Sheet (D-04 — no edit) with content (textarea, required), kind (select map|fact), a citation editor (≥1 citation, each `kind` ∈ file|commit|url|repo + a required `ref`), summary, tags, scope (`discovery:`-prefixed, defaulted only on the discovery route), visibility, calling `useCreateDiscovery`.

**Reconciled with the RPC contracts (Codex+grok HIGH, verified against proto/tools.go):** the memory form's scope/category are immutable in edit mode; schedule is create-only; create-time shared is a two-call composite (not a create-RPC field); the discovery form must send content + typed citations + a discovery-prefixed scope or the server bounces it with InvalidArgument.

Purpose: the primary write surface — a slide-over whose input survives both the in-SPA retry AND a full re-auth redirect.
Output: two Sheet-hosted form components with browser tests covering render, submit, share-warning gate, the create-only schedule gating, the discovery content+citations field set, and the D-09 retain-and-reauth path (including sessionStorage draft round-trip).
</objective>
