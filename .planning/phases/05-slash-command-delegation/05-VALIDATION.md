## Wave 0 Requirements

Existing Go test infrastructure is sufficient. First implementation tasks create generator tests
and add client-ID input/validation tests. All environment and process interactions use injected
fakes or scratch paths; no test runs real runtime registration or writes a real user home.

## Manual-Only Verifications

The slash command's branching and preview/confirmation instructions receive source review.
Automated checks prove engram's generated bytes, CLI validation, and fake execution behavior;
they do not claim to prove a third-party agent follows prose. Any actual live observation is
recorded separately with its scope and evidence.
