<objective>
Add the opaque static-token lane inside `internal/auth`: an operator-provisioned bearer token,
verified with a constant-time compare (`crypto/subtle`), mapped to exactly one distinct owner via
the shared `namespacedOwner("static_token", ownerID)` encoding, and never exposed in a log/error/
span (SC3 / D-11 / D-12 / D-13). This lane synthesizes a `TokenInfo` directly (no JWKS, no OIDC) —
by config construction a static-token owner is always non-empty, so it structurally cannot land in
the anonymous bucket.

Purpose: give headless callers with no IdP a rotatable, per-owner credential without a shared
"static service" identity (which would defeat tenancy isolation, #373).
Output: `static_token.go` (verifier type + constructor + `mcpauth.TokenVerifier`) and its safety
test suite.
</objective>
