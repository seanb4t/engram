<objective>
Add the `generic` opt-in pseudo-runtime: for an MCP client engram does not natively support,
`engram setup` prints a portable server configuration the operator can paste into that client.
The JSON shape is the `mcpServers`-keyed form captured directly from a real `.mcp.json` written by
`claude mcp add`, which is also the shape the milestone research found for Cursor — the de facto
portable convention.

`03-PATTERNS.md` explicitly hands one design question to the planner: `Runtime.Detect(env) bool`
has no "was I explicitly named" parameter, so D-14's opt-in-only behavior cannot be expressed
inside `Detect` without a name check somewhere. This plan resolves it with a structural predicate
the runtime declares about itself, consumed once in `Select` — the same
structural-predicates-over-enumerations shape `operatorCommands()` already uses in this binary.

Purpose: turn an unsupported runtime from a dead end into a documented manual path, without
inflating what a bare `engram setup` claims about the machine.

Output: `internal/setup/generic.go`, its test file, the registry edit, and refreshed goldens.
</objective>

binary, so "is it present" has no machine-dependent answer — the portable config can always be
produced. Also state, explicitly, that D-14's literal phrasing ("its `Detect()` reports not-present

`Runtime.Detect(env Environment) bool` carries no signal about whether the runtime was named, and

this file — both forbidden. D-14's stated PURPOSE is achieved instead by the default-set predicate
below: a bare `engram setup` never selects `generic` at all, so it neither claims presence nor
inflates the denominator. Record this deviation in the plan's SUMMARY as well as in the comment.

**The structural predicate.** In `runtime.go`, declare an optional interface — a single method
reporting whether a runtime is excluded from the default (no-`--runtime`) selection. `generic.go`
implements it returning true; no other runtime implements it at all. `Select`'s empty-names branch
type-asserts each registry entry against that interface and skips the ones that opt out; the
explicit-names branch is unchanged, so `--runtime generic` resolves exactly as before. This is a
structural predicate over a declared property, not an enumeration of names, so `runtime.go`'s

`Select`'s doc comment to state the new default-set rule and why it exists.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller argv → engram CLI | `--url` and `--token-file` flow verbatim into a JSON document engram tells the operator to paste into a third-party client |
| engram → operator terminal | the minified config is rendered into a `key=value` row a terminal interprets |
| engram → an arbitrary unsupported MCP client | the emitted config is consumed by software engram has no knowledge of |
