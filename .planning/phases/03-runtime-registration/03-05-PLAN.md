<objective>
Close the phase: make the preview honest, make `--token-file`'s narrowed meaning legible per row and
in `--help`, and bring the pinned help and catalog goldens back in line with what the command now
does.

Two of these are posture reversals from Phase 2 that must be stated rather than absorbed. D-10
reverses Phase 2's D-12 ("a preview shells out to nothing"): a bare `engram setup` now starts a
child process for every present runtime, and for claude-code and opencode that process dials the
network. And D-06 narrows `--token-file` so hard that Phase 2's D-16 provenance rendering
(`Bearer <from /path/to/token>`) no longer describes what `--apply` writes for a native runtime at
all — which is why D-07 requires an explicit per-row marker instead of a silently inert flag.

Purpose: leave `engram setup` in a state where reading `--help` and reading one report row tells an
operator exactly what happened and exactly what will happen — the failure shape memory
`zcev96ng18` records is a flag that is honored or inert with no signal either way.

Output: an honest preview, a per-row `token_file` marker, corrected help prose, and regenerated
goldens.
</objective>
