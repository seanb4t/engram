<objective>
Add the protovalidate runtime interceptor to the Connect chain so invalid write-RPC
payloads are rejected with `CodeInvalidArgument` before reaching the stub handlers, and
so authenticated callers (only) see field-level validation detail. This makes the
`buf.validate` annotations added in Plan 01 actually enforced at request time (D-08).

Purpose: Complete the D-08 contract — the annotations ship AND the runtime interceptor
is wired this phase — using a ~15-line hand-rolled interceptor (D-10 ordering) instead of
a new external dependency.
Output: `internal/server/connectvalidate.go` (interceptor + unit test) and the
`mountConnect` wiring in `connectapi.go`.
</objective>

  <behavior>
    - A request message that satisfies its buf.validate constraints passes through to the next handler unchanged.
    - A request message that violates a buf.validate constraint returns an error whose connect.CodeOf(...) == connect.CodeInvalidArgument, carrying the protovalidate violation detail.
    - A non-proto request payload passes through defensively (does not panic, does not error).
    - A non-validation error from the validator (not a *protovalidate.ValidationError) maps to connect.CodeInternal.
  </behavior>
  <action>
    Create `internal/server/connectvalidate.go` in package `server`. Add
    `newConnectValidateInterceptor(v protovalidate.Validator) connect.UnaryInterceptorFunc`
    mirroring the `newConnectSubjectInterceptor` factory shape from connectauth.go: return
    a closure over `next connect.UnaryFunc` that type-asserts `req.Any()` to
    `google.golang.org/protobuf/proto.Message`; if the assertion fails, call `next`
    defensively; otherwise call `v.Validate(msg)`. On a `*protovalidate.ValidationError`
    (matched via `errors.As`), return `connect.NewError(connect.CodeInvalidArgument, valErr)`;
    on any other non-nil error return `connect.NewError(connect.CodeInternal, err)`; on nil
    call `next`. Import `buf.build/go/protovalidate` (now a direct dep after Plan 01),
    `connectrpc.com/connect`, `google.golang.org/protobuf/proto`, and `errors`. Do NOT add
    `connectrpc.com/validate`.

    Create `internal/server/connectvalidate_test.go` implementing the four behaviors above.
    Construct a real validator with `protovalidate.New()`. Drive the interceptor directly by
    building a `connect.UnaryInterceptorFunc` and invoking the wrapped `connect.UnaryFunc`
    with a `connect.NewRequest(...)` for a write message that carries buf.validate
    constraints (e.g. `SetVisibilityRequest` with an empty id / zero Visibility for the
    invalid case, and a fully-populated valid case). Assert `connect.CodeOf(err)` equals
    the expected code per case. For the non-proto passthrough case, wrap a stub next-func
    and assert it was reached without error.
  </action>
