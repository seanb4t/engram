<objective>
Close #304 (embed param-key sharing) and #302 (embed body-build collapse) — the embed-cleanup subsystem slice of Phase 20 (per D-10 subsystem split). Both touch `internal/embed/embed.go`, so they are naturally grouped.

#302 collapses `embed.Client.embed()`'s two-path outbound-body build (struct-marshal for empty params vs map-merge for non-empty) into a single map-based path. #304 exports a single `embed.ReservedParamKeys` and has `config.ParseEmbedParams` consume it, so the two reserved-key lists (`["model","input"]`) cannot silently desync. RESEARCH confirms no import cycle: `internal/config` imports no `internal/*` today; `internal/embed` imports only `internal/telemetry`.

Purpose: One request-body code path and one reserved-key list remove two silent-drift/fork risks flagged in v0.9.x review.
Output: exported `ReservedParamKeys`, a single map-based `embed()`, and a config package that imports the shared list.
</objective>
