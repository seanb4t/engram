`06-REVIEWS.md` HIGH-3 demands. The first-cycle design mapped each command to "the variant exercising

tier-wide D-03 coverage. The claim must not be broader than the gate.

Create `cmd/engram/fieldset_registry_test.go` declaring
`fieldSetReports() map[string][]string` — each operator `commandKey` mapped to the variant names that
command's report builders produce. **Each report declares its own entry from its own `_test.go` file**
through the same `init()` mechanism `registerOperatorReport` already uses, so a conversion plan that
adds a variant adds it in one place and never edits a central list; provide
`registerReportVariants(key string, variants ...string)` alongside `registerOperatorReport` for that.
The variant universe is therefore declared where the variants are written, which is the closest
derivation available — see this plan's `must_haves` residual statement for what that does and does not
prove.

The table is hand-authored deliberately. RESEARCH.md's third open question asks whether that is a
legitimate continuation of D-07, and the answer recorded here is yes: it lists which CONSTRUCTOR to
call and never a fact string. D-07's objection was to hand-listed facts, which under-list silently. A
command-to-constructor mapping cannot under-list silently, because the gate below holds it set-equal to
a universe derived from the live cobra tree — hand-written, but derived-CHECKED. Put that rationale in
the file's doc comment so a reviewer reads the reasoning rather than inferring it.

Write `TestFieldSetRegistryCoversEveryOperatorCommandAndVariant` asserting THREE exact set equalities,
each with `slices.Equal` over sorted, dedup-checked slices, each reporting every mismatched element by
name — never a count, never a partition identity, never a one-directional containment check, because
this project has a recorded case where a partition identity stayed invariant under the very mutation it
appeared to guard and only exact set equality survived:

1. **Command universe.** `commandKeySet(operatorCommands())` — the live cobra-tree walk — set-equal to

   equality transitively joins the derived command universe to the complete golden set.

   `Report()` and assert it is a validated `fieldset.Set` that renders both lanes without error. Since
   after 06-01 the only way to obtain a `Set` is the validating constructor, a builder that would widen
   cannot return; the subtest's job is to prove every pair's builder is actually EXERCISED, which is
   what turns the tier-wide coverage claim from prose into a gate.
