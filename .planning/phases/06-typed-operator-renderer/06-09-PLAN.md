**The gate's unit is a `(command, variant)` pair, not a command.** This is the correction
`06-REVIEWS.md` HIGH-3 demands. The first-cycle design mapped each command to "the variant exercising
the most fields", which left every other shape structurally ungated — `revertSummary`'s refusal,
preview and applied shapes (`cmd/engram/migrate_family.go:386`) and purge's preview-versus-applied
templates (`cmd/engram/spine_review_purge.go:276` and `:294`) among them — while the plan claimed
tier-wide D-03 coverage. The claim must not be broader than the gate.

**Both halves of the pair are derived from production source.** This is `06-REVIEWS.md` cycle-2
HIGH-2's option (a), chosen over its option (b) (an AST gate over builder branches, which this
subsumes) and its option (c) (accept the residual and prove its boundary, which would have left the
hand-listed-universe failure family intact one level above the comparisons). The reason it is now
reachable: 06-01 moved each variant's identity into production code, so `operatorReport("prune-expired",
"preview", ...)` is a source-level fact a parser can enumerate — exactly as `operatorCommands()`
enumerates the cobra tree. The first-cycle design reconciled three hand-written test-side
representations against each other and could stay green under a synchronized omission; there is now
only one representation, and it is the code that runs.

Create `cmd/engram/fieldset_registry_test.go` with
`derivedReportVariants(t *testing.T) map[string][]string`: parse every non-`_test.go` `.go` file in
`cmd/engram` with `go/parser` (`parser.ParseDir` or a `parser.ParseFile` loop, `parser.SkipObjectResolution`
is fine — no type checking is needed), walk each file with `ast.Inspect`, and for every `*ast.CallExpr`
whose function is the identifier `operatorReport`, read arguments 0 and 1. Each must be an
`*ast.BasicLit` of `token.STRING` or a constant concatenation of them; anything else fails the test
naming `fset.Position(call.Pos())`. Argument 2 — the template — carries the same constant requirement,
which is what stops one call site from serving two shapes behind a computed string. Collect the results
as `(key, variant)` pairs, failing on any duplicate pair with both positions named, and failing if the
collected set is EMPTY — a parse that matches nothing must be loud, since a silent zero is this repo's
recorded fail-open shape (record `bqpfcnrnjs`).

**Argument 2 — the template — is a CONSTANT STRING EXPRESSION, which is not the same thing as a string
literal** (addresses `06-REVIEWS.md` cycle-3 MEDIUM-1). The constant requirement is what stops one call
site from serving two shapes behind a computed string, and the cycle-2 wording implemented it as
"`*ast.BasicLit` or a concatenation of them" — which REJECTS 06-04's mandated implementation. 06-04
requires hoisting each sweep sentence into a package-level `const` in `migrate_family.go` and passing
that identifier as argument 2, precisely so `migrate` and its `backfill-short-ids` alias share one
template instead of duplicating it (`06-04-PLAN.md:46`, `:248`, `:251`), and an identifier naming a Go
constant is an `*ast.Ident`. Resolve it inside the same walk, with no type checker: while parsing the
package, collect every package-level `const` in `cmd/engram` whose value is an accepted constant string
expression into a `map[string]string` of name to value. Argument 2 is then ACCEPTED when it is an
`*ast.BasicLit` of `token.STRING`, a concatenation of accepted forms, or an `*ast.Ident` PRESENT IN
THAT MAP; it is REJECTED by `fset.Position(call.Pos())` otherwise. An identifier naming a `var` rather
than a `const` is absent from the map and still fails — that distinction is what keeps this a constant
rule rather than an any-identifier rule, and deliberate red run (iv) below proves it goes red for a
variable. Arguments 0 and 1 — the `(key, variant)` identity — stay LITERAL-only and unchanged: each
must be an `*ast.BasicLit` of `token.STRING` or a constant concatenation of them, because 06-01 makes
that a hard requirement at every call site, every conversion plan writes literals, and loosening the
identity rule is not what MEDIUM-1 asked for. Residual, to be recorded: a const form this resolver
cannot fold — a cross-package const, an `iota` chain, a const whose value names another const — fails
CLOSED with a `file:line` rather than being skipped, so the gate stays sound and the executor is told
