## The re-run line: what the coverage claim actually costs (`06-REVIEWS.md` MEDIUM-3)

The first cycle asserted that the preview variant's `category`, `tags`, and `older_than` "resolve their
D-03 coverage through the re-run command the preview sentence already prints", without specifying a
construct. It does not survive contact with the one-placeholder-per-key rule. Here is the byte-level
reason, verified against source this cycle, so the executor does not rediscover it mid-task.

`purgePreviewSummary` (`cmd/engram/spine_review_purge.go:276-287`) emits five segments:

```
spine purge preview: <n> record(s) eligible (classes=<classes> scope=<scope>)
  id=<id>                                    ... one line per eligible id
<same-run limitation notice>.
<intersection scoping notice>.
re-run: engram spine-review purge --apply<class flags><scope flag><category flag><tags flags><older-than flag>
```

`purgeRerunCommand` (`:162-182`) composes that last line from `Classes`, `AllScopes`/`Scope`,
`Category`, `Tags`, and `OlderThan`. Two of those — `classes` and `scope` — are ALREADY stated in the
header line, in a different rendering (`expired` versus ` --class expired`). A field carries one
`WithRender`, and a key may be referenced by exactly one placeholder, so no top-level field can emit
both renderings. That kills the naive design: there is no set of top-level fields that reproduces the
re-run line byte-for-byte while every key is referenced exactly once.

The three options resolve it differently, and each is executable:

- **Option a — nested re-run field set.** Declare ONE field `rerun_command` whose value is a nested
  `fieldset.Set` (D-05), with child template
  `engram spine-review purge --apply{classes}{scope}{category}{tags}{older_than}` and five child
  fields, each carrying a `WithRender` that emits its own flag fragment INCLUDING the leading space, or
  the empty string when the flag does not apply: `classes` renders ` --class a --class b`; `scope`
  renders ` --all-scopes` when `AllScopes`, ` --scope <s>` when a scope is set, and `""` otherwise;
  `category` renders ` --category <c>` or `""`; `tags` renders ` --tags t1 --tags t2` or `""`;
  `older_than` renders ` --older-than <d>` or `""`. The parent keeps its own `classes` and `scope`
  fields for the header — a key collides only within one set, and parent and child are two sets. The
  parent template's last segment is `re-run: {rerun_command}`. JSON consequence, which is exactly what
  option-a licenses: top-level `category`, `tags`, and `older_than` move INTO a new `rerun_command`
  object, so `spine-review-purge.preview.json` is regenerated and every moved key is named in the
  SUMMARY. Text is byte-identical.
- **Option b — the re-run line loses its flags.** JSON is frozen, so no `rerun_command` key may be
  added and `category`/`tags`/`older_than` must stay top-level and be referenced directly. Give each a
  `WithRender` emitting its stated form and place its placeholder in a sentence clause; the re-run line
  then cannot also carry them without a second reference, so it collapses to
  `re-run: engram spine-review purge --apply` plus whatever flags are referenced nowhere else. Record
  in the SUMMARY, plainly, that the printed re-run command stops being copy-pasteable — that is a real
  operator regression and the honest cost of option-b here, not a detail.
- **Option c — the three fields take the exemption.** Text and json both frozen. The re-run line stays
  a literal-plus-`purgeRerunCommand` composite reached through ONE field, and `category`, `tags`, and
  `older_than` are entered in the closed allowlist with the rationale "value appears in the printed
  re-run line but is not reachable by a placeholder without a second reference to `classes`/`scope`".
  This is the option where the first cycle's prose claim is closest to true — but note it is an
  EXEMPTION, not coverage, and the SUMMARY must say so in those words rather than repeating "resolves
  through the re-run command".

Whichever option is selected, `purgeAppliedReport` is unaffected by this section: the applied sentence
prints no re-run line at all (`:294-309`), so its seven unstated fields are disposed of purely by the
D-08 table above.
