Added in response to `06-REVIEWS.md` HIGH-2: the first-cycle plans froze both lanes unconditionally,
which options a and b of the D-08 checkpoint necessarily violate — leaving two of three options with no
executable downstream path. All three now branch. Read the option recorded in `06-01-SUMMARY.md` and
follow exactly one row.

Task 1's pre-image freeze is unaffected under all three options: the goldens are always generated from
the pre-image first, in a commit carrying no production-code change. Only Task 2's behavior branches.

**Mechanics — the branch executes through the harness, and the harness does the branching**
(`06-REVIEWS.md` cycle-3 HIGH-1 found the cycle-2 branch tables unexecutable, because the harness
compared both lanes to one golden and sourced `-update` from the legacy lane). Do not improvise a
golden-regeneration procedure here. Each fixture this plan registers declares a `Divergence`
(`divergeNone` | `divergeJSON` | `divergeText`) and, when it is not `divergeNone`, a one-line
`DivergenceReason`. `TestOperatorReportGolden` resolves a golden path PER LANE from that declaration:
the converted lane always against the canonical `<Key>.<Variant>.{txt,json}`, the legacy lane against
`<Key>.<Variant>.legacy.{txt,json}` on exactly the lane the recorded option moved.

- **Option-c:** every fixture is `divergeNone`, no `.legacy.*` file may exist, and Task 2 regenerates
  nothing at all.
- **Option-a or option-b:** for each affected variant, in this order — (1) `cp` the canonical golden of
  the MOVING lane to its `.legacy.<ext>` sibling, preserving the pre-image bytes; (2) set that fixture's
  `Divergence` and `DivergenceReason`; (3) run the package `-update` flag, which writes the canonical
  file from `Report()` and the `.legacy.*` file from the legacy lane; (4) re-run without `-update` and
  confirm both lanes pass. Never hand-edit golden bytes.

`TestOperatorReportGoldenSetIsComplete` holds the `.legacy.*` file set equal to the declared divergences
in both directions, requires the reason to be non-empty exactly when a divergence is declared, and fails
any fixture that diverges on the lane the recorded option FREEZES — so "regenerated without a named
justification is a defect" and "under option-a the text goldens are frozen" are assertions rather than
instructions to remember. The pre-image bytes survive the conversion unchanged under all three options;
under a and b they survive in the `.legacy.*` file.
Under a and b the freeze is replaced by a justification requirement, never by silence.

**The fields this plan routes through the decision:** `migrateRemapReportDoc`'s mode-dependent pair
`would_remap` / `remapped`, both serialized unconditionally today with one always zero. Under option-a
the inapplicable key of the pair drops from the affected variant's `.json`; under option-b the sentence
gains a clause stating the zero-valued count and the affected `.txt` is regenerated; under option-c the
inapplicable field takes the exemption and neither file moves. This is RESEARCH.md Pitfall 1 and the
phase's highest-probability regression — resolve it by the recorded selection, never by a per-mode
presence guess.
