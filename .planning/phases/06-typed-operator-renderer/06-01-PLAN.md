Tests written into `internal/fieldset/fieldset_test.go` before the implementation is complete. Each is
a named `Test...` function so `go test -list` resolves it. Every one drives the PUBLIC constructor
`fieldset.New`, never an internal helper, because after this task there is no other way to obtain a
`Set` and the tests must exercise the path production code takes.

- `TestFieldSetCoverage_CatchesWidening`: `New` called with a template referencing one key while two
  fields are supplied yields a non-nil error and no usable `Set`, and the error text names the
  un-referenced key.
- `TestFieldSetCoverage_CatchesMissingField`: the symmetric direction — a template referencing a key no
  supplied field declares yields a non-nil error naming that key.
- `TestFieldSetRejectsDuplicateKey`: two `Field` values sharing one key in one `New` call yield a
  non-nil error naming the duplicated key. They collide; they never merge and never separate.
- `TestFieldSetRejectsRepeatedPlaceholder`: one template referencing the same key twice yields a
  non-nil error naming that key.
- `TestFieldSetJSONPreservesDeclarationOrder`: marshalling a five-field set produces exact bytes in
  declaration order, and the same five fields in a permuted declaration order produce different bytes.
- `TestFieldSetEmptyShapes`: a `New("")` with no fields renders as the empty string in text and as an
  empty json object; a field whose value is a zero-length list marshals as an empty json array; a
  single-element list marshals as a one-element array; and none of these outputs carries the
  four-character json null literal.
- `TestFieldSetTextIsByteExactUTF8`: a template and a value both carrying non-ASCII runes and a double
  quote render byte-identically in text mode, and the json bytes for that value equal what
  `encoding/json` produces for the same string on its own.
- `TestFieldSetConditionalSpanDrops`: a field whose present predicate is false drops its key from the
  json object and drops its whole enclosing template span — placeholder together with the literal text
  inside that span — from the rendered sentence, leaving no stray literal behind.

1. `type Field struct { key string; val any; present *bool; render func(any) string; sep string }` and
