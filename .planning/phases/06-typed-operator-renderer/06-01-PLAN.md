**(a) `cmd/engram/fieldset.go`** — SPDX header, `package main`, stdlib imports only (`encoding/json`,
`fmt`, `slices`, `strings`, `time`). Declare
`type Field struct { Key string; Val any; Present *bool; Render func(any) string; Sep string }` and
`type FieldSet struct { Text string; Fields []Field }`, plus `func present(cond bool) *bool`.
`Present` is a pointer so its zero value nil means always-present — the safe default — and a non-nil
false is the D-06 drop. `Render` overrides TEXT formatting only. `Sep` is the join separator for a
`[]FieldSet`-valued field and is REQUIRED non-empty on such fields: per RESEARCH.md assumption A4 there
is no correct default, because `statusSummary` joins inline while the other six list reports join on a
newline.

Write ONE parser, `parseFieldSetText(text string) ([]textSegment, error)`, returning an ordered segment
list of literal, placeholder, and conditional-span segments. Placeholder syntax is `{key}` for an
unconditional reference and a bracketed span carrying its own literal text plus one `{key}` for a
conditional reference, emitted whole or dropped whole. Doubled delimiters escape to a single literal
delimiter. An unmatched or nested delimiter is an error, never silently literal text. The scanner walks
BYTES; every delimiter it recognises is ASCII and so cannot appear inside a multi-byte UTF-8 sequence,
which is what makes byte scanning safe for arbitrary UTF-8 template text. Substituted VALUES are
written straight to the output buffer and are never re-scanned for delimiters.

`validateFieldSet(fs FieldSet) error` calls that same parser and asserts exact SET EQUALITY between the
declared key set and the referenced placeholder key set — never a count and never a partition
identity, because this repo's recorded gotcha `01mdq5qq9j` documents a partition identity that stayed
invariant under the very mutation it appeared to guard. It rejects a duplicated `Key`, rejects a key
referenced twice, requires a field carrying a non-nil `Present` to be referenced from a conditional
span rather than a bare placeholder, requires a non-empty `Sep` on a `[]FieldSet`-valued field, and
recurses into `FieldSet` and `[]FieldSet` values one level at a time (D-05). Every error is built with
`fmt.Errorf` naming the offending key or index — never a bare boolean — matching
`internal/surfaces/rules.go`'s named-error style.

`(fs FieldSet) RenderText() string` walks the parsed segments. `(fs FieldSet) MarshalJSON()` walks
`fs.Fields` in declaration order, writing the structural bytes by hand and delegating every scalar to
`encoding/json` so escaping is not re-derived. Type dispatch is an explicit Go type switch over `any`
covering `string`, `bool`, the integer widths the fifteen reports actually use, `float32`, `time.Time`,
`[]string`, `FieldSet`, and `[]FieldSet` — no reflection-based dispatch (D-01), no templating-engine
import (D-01), and no Go map as the object body, since map iteration order is randomised and
`encoding/json` sorts map keys, which would silently reorder every document.

If Task 1 selected option-c, additionally implement the exemption exactly as the developer worded it,
with its allowlist held set-equal to a checked-in inventory by its own named test.
