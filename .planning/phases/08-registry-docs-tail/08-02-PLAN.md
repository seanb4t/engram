unqualified version is what makes a rollback look safer than it is:

1. **Reads and recall are unconditionally safe.** A binary reading a record stamped newer than its
   own constant returns it normally and never rejects, hides, or downgrades it. The version is not a
   filter key, so recall does not narrow on it either.
2. **The normal write path preserves the higher stamp.** `payload()` computes the version as the

   ordinary path cannot lower it.
