<objective>
Build the sweep half of the shared bounded-read mechanism: a byte-budget extension of
`scrollAllPoints` (the package's one whole-spine iterator), plus the per-view record ceiling it is
sized from. Each budgeted `ScrollAndOffset` requests a record count derived arithmetically from a
2 MiB per-RPC byte budget and the TRUE per-record payload ceiling of the view being read, so no
single RPC can overflow for records that respect the caps; a legacy record that does not is
re-read one at a time and, if a single record still overflows, the sweep fails with the named
`store.ErrResponseTooLarge` rather than skipping it.

Decisions implemented: D-02 (count = `floor(rpcByteBudget / maxRecordBytes)`, where
`maxRecordBytes` is derived PER VIEW from content + summary + tags + citations + an allowance for
payload fields no write cap bounds — never content alone), D-03 item 2 (extend `scrollAllPoints` in
place, same name, same `operatorMigrationEmitters` classification), D-04 (the primitive takes the
caller's payload selector, bundled with its ceiling as a `readView`, so a projection can never be
paired with the wrong ceiling), D-06 (fixed 2 MiB budgets as package `var` seams), D-07 (batch-of-1
fallback, then the named error), and D-09/D-10's rationale on the read side (the ceiling derives from
the CONFIGURED caps through `RecordCaps`; plan 03-03 wires the production values). Framing (D-00):
extend the existing iterator and option pattern in place; `proto.Size` over the received
`*qdrant.RetrievedPoint` for measurement; no new dependency.

Behavior preservation: this plan migrates no caller. Every existing caller passes
`unbudgetedView(<its old selector>)`, which keeps today's `spineScrollBatch`-per-RPC loop with no
fallback; Phase 5 replaces each such call and then deletes the constructor, and its closing check
is that no `unbudgetedView(` call remains (plan 03-04's inventory records every one).

Residual, recorded rather than resolved (no user decision exists to cap them): payload fields with no
write cap — `scope`, `repo`, `workspace`, `worktree_path`, `base_dir`, `source`, the `supersedes`
list, and each citation's `ref`/`locator`/`pin` — are budgeted by documented allowances, not proven
bounds; a record exceeding an allowance is caught by the batch-of-1 fallback and, at worst, fails
with the named error (never silently).

Purpose: REQ-byte-budget-pages (sweep primitive); the ceiling and budgets plan 03-04's ordered-page
helper reuses.

Output: `internal/store/boundedread.go`, the in-place `scrollAllPoints` extension, real-Qdrant proofs
over both fixture shapes and both views, legacy-record fallback proofs, and exact-arithmetic unit
tests.
</objective>
