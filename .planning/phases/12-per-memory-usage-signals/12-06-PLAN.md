<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → MCP/Connect get handler → usageQueue | Untrusted caller triggers a counter bump only after passing the existing GetReadable ownership gate; enqueue is fire-and-forget. |
| client → tool args | access_count/last_accessed_at are read-only outputs; no tool argument writes them. |
| store/Connect read → response serialization | The two new fields are serialized only for records the caller already proved readable. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-01 | Tampering | tool args (storeArgs/updateArgs/idArgs) | high | mitigate | No arg struct exposes access_count/last_accessed_at; both are server-set. Verified by the test that update_memory only bumps via the server path, and by grep that neither field appears in a client-writable arg struct. |
| T-12-02 | Information Disclosure | access_count/last_accessed_at on recallView + memoryToProto | high | mitigate | Both fields ride the EXISTING per-actor read gates (GetReadable, List's owner/scope filter); serialization happens only on already-gated records. No new read path bypasses ownerOrSharedCondition/ownerScopeFilter; neither field is indexed/filterable (Plan 01). |
| T-12-03 | Denial of Service | get-path write amplification | high | mitigate | Get-path bump is async best-effort via the bounded usageQueue (drop-on-full); ENGRAM_USAGE_SIGNALS=false disables the read-path write entirely (D-09). |
| T-12-14 | Repudiation | counting on denied/ErrNotFound get | medium | mitigate | tryEnqueue fires only on the err==nil success branch; the denied-get test proves no increment on failure (D-01). |
| T-12-05 | Tampering (integrity) | ranking isolation end-to-end | high | mitigate | No counting on search/list membership (D-02 test); usage counters never enter rerank (D-08, Plan 01 test). |
| T-12-SC | Tampering | package installs | low | accept | No new external packages introduced by this phase (RESEARCH Package Legitimacy Audit: N/A — Go-only, all deps vendored). |
</threat_model>
