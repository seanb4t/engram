<objective>
Stop the four discard sites from throwing away already-authorized hits when the follow-up
`ListScopes` coverage query fails, and make "coverage unknown" a first-class, wire-visible third
state on both transports.

One helper — `(*deps).searchedScopes` — sits behind all four sites, so the fix lives there once:
it returns the coverage state as a value (no error to propagate), logs the real cause server-side,
and the four call sites lose their abort branch.

Decisions covered: D-01 (the RPC succeeds), D-02 (log the cause, keep the wire generic), D-03 (the
three states stay distinguishable), D-04 (`scopes_unknown`, field 7 and field 4), D-06 (the fix
lives inside the helper; scope is exactly the four surfaces).

Purpose: REQ-cross-spine-partial's server half — the hits survive, and a consumer can tell the
three coverage states apart on MCP and on Connect.

Output: two additive proto fields plus three regenerated trees, one value-returning helper, four
un-discarded call sites, one new MCP result-map key, and one new test file proving all of it.
</objective>
