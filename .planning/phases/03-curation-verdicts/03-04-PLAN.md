## Executor notes (every task)

- Sequential main tree; never any git stash subcommand; explicit pathspec; Conventional Commits; the session's attribution trailer.

- Keyed literals with `id` and `label` first on the same line: `{id: "P01", label: "updates", recordA: "…", recordB: "…"}`. The verification commands read those two fields with `rg`.
