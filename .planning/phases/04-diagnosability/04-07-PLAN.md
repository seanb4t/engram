<objective>
Ship the guidance in the same phase as the contract it describes.

This repo's standing convention (`yaj7dqz9qq`) is that a new agent-facing contract with no guidance
is an INCOMPLETE feature — verification treats missing guidance as a gap, not a follow-up. This phase
publishes three new contracts at once: an error grammar an agent parses, a hint vocabulary an agent
branches on, and a Connect code mapping a client branches on. Two of the three are one-way doors. All
three are useless undocumented, and the hint vocabulary is actively harmful undocumented, because an
agent that cannot discover the codes will go back to pattern-matching message text — the exact habit
that produced issue #360's misattribution class.

There is also an operator half. The Cedar decision diagnostics from plan 04-02 are debug-level and
therefore invisible unless someone knows to raise the level and what to expect when they do.

Purpose: make three new contracts discoverable and correctly used, not merely present.
Output: one new reference page and four updated surfaces.
</objective>
