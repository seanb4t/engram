<objective>
Give each Qdrant-backed test package a namespace it owns, enforced by the construction seam rather
than by everyone remembering to type a prefix.

Purpose: with four packages sharing one Qdrant instance, collection naming is the only thing keeping
them from writing over each other's fixtures mid-run. Plan 01-04 resolved the one live collision;
this plan makes the property structural, so a collection name added next month cannot silently
reintroduce it.
Output: a `testCollectionPrefix` constant and a prefix-enforcing construction seam in all four
packages, with every hardcoded collection name in `internal/store` and `internal/server` routed
through it.
</objective>

Introduce the construction seam that makes the prefix structural, and prove it on one package before

In each of the four Qdrant-backed packages' test scope, add `newTestStore(t testing.TB, c *qdrant.Client, name string) *store.Store`
(unqualified `New` inside `internal/store`, `store.New` in the other three). Its first act is to
assert the name carries the package's own `testCollectionPrefix` and call `t.Fatalf` naming the
offending value if it does not. Then it constructs the store. Use `testing.TB` rather than
`*testing.T` so a construction site inside a `testing.TB`-typed helper can thread it through without
a signature fight; where a current construction site has no test handle in scope, thread one in
rather than dropping the assertion.

This is the mechanism, and it is a runtime assertion on purpose. A source-level check can be routed
around by assigning the raw name to a variable first; a `t.Fatalf` inside the one function every test
store is built by cannot.

server's port and one from a fresh UUID, and RESEARCH.md verified both are already collision-safe.

through `testCollection` so the constant is the single source of truth rather than a comment about a
literal elsewhere in the line. The generated suffix is unchanged.

Route `internal/server`'s two remaining raw names through the seam: the store construction and the

Preserve the existing delete-before-create discipline everywhere the seam touches. Each test that

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| four concurrently-running test packages → one shared Qdrant | Isolation formerly provided by separate containers is now provided only by collection naming. |
| a test's collection name → the shared instance's namespace | A name that skips the seam writes into the shared namespace unchecked. |
