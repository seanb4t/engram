<objective>
Build the in-process worker pool that is the behavioral heart of this phase:
`internal/server/summaryqueue.go`. A bounded, non-blocking, nil-safe queue whose
workers drain record ids through the existing `Store.FillSummary` seam with
bounded `backoff/v5` retry, plus a graceful best-effort drain — and a matching
deterministic test file. No handler or lifecycle wiring yet (that is Wave 3);
this plan delivers the queue as a self-contained, fully-tested unit.

Purpose: SC#1 (worker drains via FillSummary), SC#2 (never blocks the write
path), and the D-03/D-04/D-08 behaviors all live in this one file. Isolating it
lets the deterministic tests (drop, never-block, retry-give-up, drain-within-budget)
run without Qdrant, off the write path, using an injected fill closure.

Output: `summaryQueue` type + `newSummaryQueue`/`tryEnqueue`/`worker`/`Start`/
`Shutdown`/`Wait` + a deterministic test suite. `go test ./internal/server/...`
green with no `time.Sleep`-based synchronization.
</objective>
