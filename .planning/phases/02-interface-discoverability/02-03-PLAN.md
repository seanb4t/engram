<objective>
Widen the rule registry from the one tracer rule to every conditional rule this phase's structural
marker selects, convert each rejection site to `conditionalErrf`, and regenerate every surface.

Purpose: D-01 anchors completeness on the hint code as a structural marker rather than a curated
list, precisely because a curated list is silent on the failure this requirement exists to prevent — a
new conditional rule that never reaches either surface. D-02 gives the selector two independent
markers (field arity OR one of the four cross-field hint codes) so a rule filed under the wrong code
is still caught. Phase 1's D-08 already declared the paging model becomes correct-by-reading here, so
the paging trio is an expected member of this registry, not an optional extra.

Output: the complete registry, every in-scope site converted, the one documented exclusion, the
residual sweep test, the `errStaleSummary` decision, the upgrade note, and regenerated surfaces.
</objective>
