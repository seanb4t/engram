## Flagged assumptions (not silently dropped)

- **"While understanding is on" means effectively on (research Open Question 1):** the timeout is validated for explicit `jev` AND for unset-with-provider-jev, so a default-on deployment cannot start with a bad timeout that only fails later. A no-provider deployment never has it checked.
- **Disclosure level is Warn**, following the `logSearchRerankAuditEnabled` pattern D-15 names (query text egress an operator may not have opted into consciously should keep saying so); `logSearchRankerEnabled`'s Info level is the one it does not follow.
- **Unknown values:** Validate rejects them at startup; the server resolver's own fallback (off, with a Warn) only matters for an out-of-band call that bypassed Validate.
