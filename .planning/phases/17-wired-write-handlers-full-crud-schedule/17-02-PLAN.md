<objective>
Two coupled refactors that unblock write-handler wiring: (1) extract a narrow
`memStore` interface covering exactly the store methods `deps.*` calls and retype
`deps.st` to it (D-10 prerequisite — the fake store cannot exist while `deps.st`
is a concrete `*store.Store`); (2) thread an explicit `caller` value through every
`deps.*` method so identity is resolved once by the transport and passed in,
never read from ctx inside a handler (SC1/D-01/D-02/D-03).

Three verified landmines are pre-empted here: the store-interface carve lands
BEFORE any handler touches `d.st` (landmine 1 ordering); `callerFromTokenInfo`
falls back `Actor` to the resolved owner because the Connect cookie lane never
sets `TokenInfo.UserID` (landmine 3); and `updateArgs.Content` becomes `*string`
so a tags-only Connect update cannot silently blank stored content (landmine 2).

Purpose: one caller-parameterized `deps` core both transports call — the
structural basis for SC2's "identical code path." Output: `store_iface.go`, the
`caller` seam in `identity.go`, and the signature-threaded `deps.*` surface.
</objective>
