<objective>
Wire the six Connect write RPCs and rewire the read handlers onto the shared,
typed `deps.*` core, backed by a scripted-spy fake store and a single production
error mapper. Today `engramAPI` has ZERO methods for the six write RPCs (they fall
through to `UnimplementedEngramServiceHandler`); this plan authors six real thin
adapters. The read handlers move off direct `a.d.st.*` onto the 17-06 typed core
read methods, closing Pitfall 1 for reads AND writes without regressing the Connect
read contract.

Four review fixes are load-bearing (round-1 + round-2):
- **Production connectError mapper (HIGH):** the original `ErrNotFound`+
  `ErrInvalidArgument`-only mapping sent expected business failures (rule
  immutability, stale-summary/concurrency conflicts) to `CodeInternal`. A single
  `connectError(ctx, err)` mapper in the handler layer maps typed sentinels to
  `CodeNotFound` / `CodeInvalidArgument` / `CodeFailedPrecondition` / `CodeAborted`
  / `CodeInternal`. Round-2: the mapper takes `ctx` so the CodeInternal branch logs
  request-scoped fields (finding LOW); and because 17-02 now wraps `parseWindow`
  (past `not_after`, ordering) and `validateRuleSummary` with `store.ErrInvalidArgument`,
  those semantic failures map to `CodeInvalidArgument` not `CodeInternal` (finding 5).
- **SearchDiscoveries k=20 (finding 7):** the read rewire must pre-apply the Connect
  k=20 default in the SearchDiscoveries adapter before calling `deps.searchDiscovery`
  (whose internal default is the MCP 8) — the same one-path-missed class as the
  round-1 SearchMemories k fix.
- **Scripted-spy fake (HIGH):** the fake is a spy that records method+subject/args
  (for 17-05 delegation parity) rather than reimplementing full store authz (which
  drifts). The real Qdrant isolation suite stays the authz gate. The spy-backed
  deps also needs a non-nil embedder (valid StoreMemory/StoreDiscovery/
  ScheduleMemory reach `d.em.Embed`).
- **Read rewire without regression (HIGH):** Connect read handlers build the 17-06
  typed core superset (all fields + Connect k=20) — no dropped field.

Landmine 1 is pre-empted: `TestWriteRPCNegativeMatrix` builds `d := &deps{}` with a
nil store — safe only while the writes are Unimplemented. The spy fake + the
negative-test fix land in THIS plan alongside the handler bodies.

Addresses review concerns: connectError mapper (HIGH), by-id result mapping usage
(HIGH), read rewire regression (HIGH, via 17-06), spy fake + non-nil embedder (HIGH);
**round-2: connectError(ctx, err) signature (LOW), store.ErrInvalidArgument mapping
covers parseWindow/rule-summary (finding 5), SearchDiscoveries k=20 (finding 7)**.
</objective>
