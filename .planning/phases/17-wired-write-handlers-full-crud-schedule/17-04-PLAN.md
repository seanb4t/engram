<objective>
Wire the six Connect write RPCs and rewire the read handlers onto the shared
`deps.*` core, backed by a new hermetic fake store. Today `engramAPI` has ZERO
methods for the six write RPCs — they fall through to the embedded
`UnimplementedEngramServiceHandler`; this plan authors six real thin-adapter
methods. Simultaneously the five read handlers move off direct `a.d.st.*` calls
onto the caller-threaded `deps.*` read methods (D-07), closing the milestone's #1
risk (Pitfall 1) for both reads and writes.

Landmine 1 is pre-empted here: `TestWriteRPCNegativeMatrix` builds `d := &deps{}`
with a nil store — safe only while the write RPCs are Unimplemented. The moment a
real handler touches `d.st`, it nil-panics. So the fake store + the negative-test
fix land in THIS plan, alongside the handler bodies, not after.

Purpose: SC2/SC3 become live — both lanes run the identical code path. Output:
`fakestore_test.go`, the six write methods + rewired reads in `connectapi.go`, and
the corrected negative matrix.
</objective>
