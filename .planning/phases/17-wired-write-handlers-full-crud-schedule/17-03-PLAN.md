<objective>
Author the D-09 conversion layer (`protoconv.go`) that translates the six Connect
write request messages to the internal `*Args` structs (and write results back to
proto responses), with round-trip unit tests. This is the seam that keeps every
write handler a thin adapter (SC2): the handler resolves the caller, calls
protoconv, calls the one `deps.*` method, and maps the result — no conversion or
validation logic in the handler body.

The mask-driven `content` mapping is the second half of landmine 2: when
`content` is absent from `update_mask.paths`, protoconv must produce a nil
`updateArgs.Content` (Plan 02 made the field `*string`), never forward the proto
zero value — otherwise a tags-only Connect update blanks stored content.

Purpose: a tested, single-home conversion layer feeding Plan 04's handlers.
Output: `protoconv.go` + `protoconv_test.go`.
</objective>
