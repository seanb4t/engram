names it in a rejection; this plan makes sure nobody has to hit that rejection to learn the number.

behavior change callers can be broken by.

removed from each), D-02 (one number cited by every doc), D-03 (the rule listing's published
ceiling), D-04 (the BREAKING upgrade entry and the project decision record), D-08 (each surface's
zero-count default, documented as it already behaves).

Purpose: REQ-list-limit-contract-decided — the chosen contract is implemented, documented, and the
wire-visible change is explicitly called out as breaking.

project decision row; a durable docs gate; and the regenerated stub trees.
