## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-18-05 | Tampering | reseal interceptor ordering | medium | mitigate | Appended LAST (innermost) in WithInterceptors so it fires only after subject/CSRF/validate pass; the interceptor branches on resp==nil / err!=nil and skips re-seal on any rejection (RESEARCH §1/§2). Interceptor-contract tests (Task 1) prove the skip-on-error/nil behavior. |
| T-18-07 | Denial of Service | reseal failure surfacing as a client error | medium | mitigate | The interceptor returns resp, nil regardless of the reseal call (D-04), and Reseal itself is void-return (Plan 18-01) — a transient seal failure structurally cannot fail the request. |
| T-18-04 | Information Disclosure | reseal error paths on the response | medium | mitigate | Reseal (Plan 18-01) silently no-ops on failure and never logs identity; the interceptor adds no error surface. |
| T-18-06 | Denial of Service | engram_csrf cookie lapse mid-session | medium | mitigate | The injected Reseal refreshes both the session and engram_csrf cookies together (D-08), emitted onto resp.Header() via this interceptor, so a slid session never breaks writes on a lapsed CSRF cookie. |
| T-18-SC | Tampering | package-manager installs | low | accept | No package installs this phase — zero new Go dependencies (RESEARCH §6). |
