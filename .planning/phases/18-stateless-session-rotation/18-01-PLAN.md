<objective>
Add the stateless sliding-expiry re-seal primitive to internal/webauth: a new
best-effort `Reseal` method on `*webauth.Handler` that re-parses the session cookie,
and — once the session crosses the ½-TTL threshold — re-seals BOTH the session cookie
(fresh absolute expiry) and the engram_csrf cookie (refreshed Max-Age) directly onto an
`http.Header`. This is the pure crypto/clock core; the Connect interceptor that emits
these cookies onto a response is Plan 18-03.

Purpose: Satisfies REQ-session-rotation SC1 (threshold re-seal), SC3 (forward-monotonic
under concurrency), SC4 (hard expiry stays strict; skew is threshold-only), and D-08
(both cookies refreshed) — with zero server-side state (honors DEC-u9v).
Output: internal/webauth/reseal.go + tests, and an SC4 guard test pinning
resolver.go's hard-expiry check unchanged.

    Add method `func (h *Handler) Reseal(respHeader http.Header, r *http.Request)` — void return, best-effort:
      1. Read the session cookie: c, err := r.Cookie(sessionCookieName); on err, return (silent no-op).
      2. sess, err := h.codec.Unseal(c.Value); on err, return (silent no-op).
      3. remaining := sess.Expiry.Sub(nowUTC()). If remaining >= resealThreshold+resealSkew, return (not yet due — this bounds Set-Cookie churn to ~once per 6h of continuous activity, D-05). This comparison is the ONLY place resealSkew is used.
      4. Compute the fresh session with an ABSOLUTE expiry: Session{Owner: sess.Owner, Expiry: nowUTC().Add(sessionTTL)} — never sess.Expiry+delta (D-06). sealed, err := h.codec.Seal(that); on err, return (silent no-op — never turn a handler success into an error, D-04).
      5. Emit both cookies onto respHeader via the shim: h.setCookie(headerOnlyWriter{respHeader}, sessionCookieName, sealed, sessionTTL) then h.setReadableCookie(headerOnlyWriter{respHeader}, CSRFCookieName, h.signer.Token(sess.Owner), sessionTTL). The CSRF token value is the same Owner-bound HMAC as at login, so only its Max-Age refreshes (D-08).

    Reseal MUST NOT return an error, MUST NOT log the owner value on any failure path, and MUST NOT touch resolver.go. Do NOT redeclare nowUTC — reuse the package var.
