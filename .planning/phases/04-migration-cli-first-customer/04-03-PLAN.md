<objective>
Build the `engram migrate` command family — `migrate` (forward sweep preview/apply with in-apply-closure re-preview per the purge pattern — H5), `migrate status` (read-only histogram), `migrate revert --to <v>` (reverse inverses with shared exported `PreviewRevert` accessor — M8) — as subcommands routed through the standard destructive-tier `registerDestructive`, generalize that mechanism's gate so the additive `migrate` sweep can use it (the phase's single required non-consumption code change), add the three toolclass blast-radius rows, prove preview/apply parity at the CLI boundary via identity set (H6/SC3), add a 5-minute default timeout for the migrate family (H8), update TestDestructiveCommandsRequireApply to derive from !ReadOnly (M12), and add PreviewRevert to the store interface (M8).

Key cycle-2 resolution changes from the prior plan:
- H5: The manifest bridge is NOT a package-level var. The apply closure calls `Store.Migrate(DryRun:true)` inside itself, captures the preview manifest, then calls `Store.Migrate(Manifest: previewManifest)` — all within the same invocation, mirroring the purge precedent (`spine_review_purge.go:339-377`).
- H8: The migrate family carries a 5-minute default `--timeout` via a shared `migrateWithTimeout` helper. The timeout is NOT removed (as the prior plan proposed for the backfill alias — that will be handled in 04-04 by KEEPING the timeout there too).
- M8: Exported `PreviewRevert(ctx, to) (RevertPlan, error)` on Store. Added to `migrateFamilyStore` interface. Both preview and apply closures call this same exported method.
- M12: `TestDestructiveCommandsRequireApply` derives the `--apply` set from `!ReadOnly` (the D-16 generalization), adding a `migrate` row to a new `mutatingCommandNames()` helper derived from `!op.Class.ReadOnly && op.CLICommand != ""`.

Purpose: This is the operator-facing surface for all six Phase-4 requirements except the backfill alias (04-04) and the never-automatic startup cap (04-02). It relies on the store methods from 04-01 (Store.Migrate + DryRun + manifest) and 04-02 (Store.MigrateStatus, Store.Revert, and the new exported PreviewRevert).

Output: a new `cmd/engram/migrate_family.go`, the generalized `registerDestructive` gate with M9 documentation, three toolclass rows, the shared migrate report envelope, a local store interface seam (M7) that includes `PreviewRevert` (M8), a shared `migrateWithTimeout` helper (H8), the CLI + catalog conformance tests with manifest-based parity (H6), and updated `TestDestructiveCommandsRequireApply` deriving from `!ReadOnly` (M12).
