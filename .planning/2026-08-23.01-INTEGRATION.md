## Detailed Findings

### B01 — [#559](https://github.com/seanb4t/engram/issues/559) — BLOCKER: AGENTS.md preservation is lost when reading the existing index fails

- **Requirements:** REQ-skills-agents-md-fallback (unsatisfied). Also affects the correctness of the successful skills result displayed through REQ-setup-partial-failure-legible and the preservation statement in REQ-docs-setup-documented; those consumer connections themselves are present.
- **From/to:** P3 Codex target → P4 filesystem installer → P2 result reporting/P6 guidance.
- **Break:** `internal/skills/install.go:152–155` treats every `ReadFile` failure as empty content. `Splice(nil, block)` creates only the managed block; `install.go:188–193` overwrites the whole target and reports Wrote when writing is permitted. Read and write permission are independent, so an existing writable but unreadable index can take this path. A transient read failure with successful subsequent write has the same result.
- **User effect:** unrelated user guidance is erased and the skills facet reports success. Re-running setup cannot recover erased outside-block text.
- **Reproduction:** a temporary Go overlay injected `TestAuditUnreadableIndexLosesOutsideBytes` into package skills without modifying repository files. It called the production `Install` with `FormatAgentsMD`, a fake in-memory file containing user guidance, an index read returning `os.ErrPermission`, and a successful writer. Result: `index_read=permission-denied index_write=succeeded outside_bytes_lost=true report_error=<nil> wrote=[/synthetic/.agents/skills/example/SKILL.md /synthetic/.codex/AGENTS.md]`.
- **Acceptance context:** P4 Context D15 (`04-CONTEXT.md:259–268`) explicitly preserves outside bytes and refuses guessing at ambiguous regions. D16 (`272–280`) accepts the non-atomic/symlink-following crash window, but does not waive preservation after a read error. The implementation comment explains the behavior; it is not an accepted requirement exception.
- **Required correction:** preserve the existing file and report a skills failure on read errors other than confirmed nonexistence. Keep independent skill-file work/reporting. Add a meaningful fake-environment regression for permission/transient errors and the report/exit propagation. No fix was made in this audit.

### W01 — [#560](https://github.com/seanb4t/engram/issues/560) — WARNING: real subprocess timeout is not returned as the executor's timeout error

- **Requirements:** REQ-setup-non-interactive, REQ-register-cli-surface-drift-legible, REQ-setup-idempotent (edge-case reliability).
- **From/to:** P3 `Environment.Run` production adapter → shared executor → P2 report/exit classification.
- **Break in error semantics:** `internal/setup/environment.go:94–100` converts `*exec.ExitError` to a numeric exit and nil error without checking `ctx.Err()`. `exec.CommandContext` killing an already-running process for deadline expiry takes that branch. The documented seam promises a non-nil timeout error, and `internal/setup/apply.go:303–306` relies on it to stop apply after a timed-out first probe.
- **Reproduction:** a temporary Go overlay called actual `osRun` with a 50ms context and `/bin/sleep 5` (an owned adapter test, no third-party runtime). Result: `context_error=context deadline exceeded adapter_error=<nil> adapter_exit_code=-1`.
- **Effect:** the process is still killed, so this is not an unbounded-wait finding. A timed-out first probe can be treated as an ordinary completed nonzero probe and apply proceeds; a post-write timeout can participate in raw-byte convergence comparison. Action failures remain legible by exit -1, but lose the timeout reason. Fake seam-error tests do not establish real adapter parity.
- **Correction direction:** return the context error when cancellation/deadline ended execution before translating ordinary exit errors. Keep the existing per-runtime reporting path.

func TestAuditUnreadableIndexLosesOutsideBytes(t *testing.T) {
    index := "/synthetic/.codex/AGENTS.md"
    prior := []byte("User-owned guidance outside any managed block.\n")
    files := map[string][]byte{index: prior}
    env := fakeInstallEnv(files) // existing package test helper
    originalRead := env.ReadFile
    env.ReadFile = func(path string) ([]byte, error) {
        if path == index { return nil, os.ErrPermission }
        return originalRead(path)
    }
    report := Install(env, Target{
        Format: FormatAgentsMD, Dir: "/synthetic/.agents/skills", IndexFile: index,
    }, []Skill{{Name: "example", Summary: "Example guidance",
        Files: []File{{Path: "SKILL.md", Content: []byte("skill guidance")}}}})
    lost := !bytes.Contains(files[index], prior)
    t.Logf("outside_bytes_lost=%v report_error=%v wrote=%v", lost, report.Err, report.Wrote)
    if !lost || report.Err != nil { t.Fatal("expected current defect was not reproduced") }
}
